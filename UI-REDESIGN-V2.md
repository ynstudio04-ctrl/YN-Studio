# YN Studio UI/UX Redesign V2

This version applies the approved purple/white visual direction to both apps while preserving the existing backend, routes, authentication, API calls, Supabase integration, order/payment/savings flows, and JARVIS functionality.

## Admin
- Modern light dashboard surface with purple brand language.
- Dark navigation rail retained for strong app identity.
- Refined topbar, search, profile and controls.
- New dashboard workspace/action layout and status panel.
- Existing JARVIS remains a floating bottom-right orb.
- Tables, cards, forms and buttons receive a consistent visual system.
- Responsive behavior for smaller screens.

## Customer
- Mobile-first purple/white redesign.
- Rounded card system and cleaner spacing.
- Purple hero/search area.
- Wallet balance surfaced on the home screen.
- Orders and Wallet promoted as primary actions.
- Quick actions reorganized into compact tiles.
- Bottom navigation redesigned as a floating navigation bar.
- Existing customer routes, themes and API behavior are retained.

## Important
The ZIP does not include `node_modules`. Run `npm install` inside `client` and `customer` after extracting, then use the existing build/deploy commands.
