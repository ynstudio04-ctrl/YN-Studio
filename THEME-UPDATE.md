# Customer Secret Themes Update

The customer home now uses a full-screen themed layout when USAGITIME or CHIIKAWATIME is active. Character artwork is integrated into the welcome card, customer ID, orders, wallet, quick actions, recent-order area, and bottom navigation.

Codes:
- USAGITIME
- CHIIKAWATIME
- RESETTIME
- NORMALTIME

The theme is stored in localStorage and activated from Customer Profile. The audio is an original Web Audio synthesized squeak/chirp.

Payment upload/storage fixes from the previous project are retained.
